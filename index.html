🔑 휴대폰 연결 설정

계좌 정보는 비공개 저장소에만 있습니다. 이 화면은 아래에 붙여 넣은 내 GitHub 토큰으로 그 저장소에서 직접 받아옵니다. 토큰이 없으면 아무 계좌 정보도 표시되지 않습니다.

토큰 만드는 방법 (처음 한 번만, 3분)
  1. GitHub 토큰 만들기 열기 → GitHub에 로그인합니다.
  2. Token name 에 한투ETF현황 이라고 적습니다.
  3. Expiration 은 90 days 를 권합니다. (만료되면 이 화면에서 새 토큰만 넣으면 됩니다.)
  4. Repository access → Only select repositories → kis-etf-rebalancer 하나만 고릅니다.
  5. Permissions → Repository permissions 에서 딱 세 가지만 바꿉니다.
    • Contents → Read-only (계좌 현황 읽기)
    • Actions → Read and write (실행 요청·실행 이력)
    • Variables → Read and write (일시중지 스위치)
  6. 맨 아래 Generate token → github_pat_ 로 시작하는 값을 복사합니다. 이때만 보이니 바로 복사하세요.
  7. 아래 칸에 붙여 넣고 저장을 누릅니다.

토큰은 이 휴대폰 브라우저에만 저장되고, GitHub 주소로만 전송됩니다. 다른 곳에는 저장되지 않습니다.
